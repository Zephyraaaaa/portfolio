## 设计理念

用墨竹从两侧框住纸面，把留白留给绿色字母。熊猫和竹叶落在画面下方，与中间的字母形成高低错落的排版。

## 成果展示

竖版动态海报约 11 秒。纸面与标题先出现，竹影和熊猫陆续入画，绿色字母逐步显现。静态海报呈现完整构图。
